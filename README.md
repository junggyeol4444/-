# MYVOCAL Studio

브라우저에서 실행되는 AI 음악·영상 제작 워크스테이션 프로토타입입니다. 소개용 랜딩 페이지가 아니라 실제 편집 작업을 시험할 수 있는 프로그램 UI입니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 현재 구현된 기능

- 멀티트랙 타임라인, 클립 선택·드래그·스냅, 트랙 추가
- 재생·정지·되감기와 Web Audio 기반 데모 반주 재생
- 트랙 음소거·솔로·볼륨과 마스터 볼륨 조절
- 가사 직접 편집 및 AI 가사 다시 쓰기
- 피아노 롤, 오토메이션, MV 스토리보드 편집 패널
- 자연어 명령으로 트랙을 수정하는 AI Producer 시뮬레이션
- Music, Voice, Character, Video, Library 작업 공간 전환
- 렌더링 진행, 내보내기, 키보드 재생 및 실행 취소 단축키

> 현재 저장과 AI 생성은 프론트엔드 시뮬레이션입니다. 음성 모델 학습, 외부 생성 Provider, 실제 영상 렌더러를 연결할 수 있도록 편집 워크플로를 먼저 구현했습니다.
