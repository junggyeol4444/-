# MYVOCAL Studio

AI 음악 제작, 보이스 모델, 캐릭터, 뮤직비디오 워크플로를 하나의 화면으로 구성한 인터랙티브 웹 프로토타입입니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 주요 기능

- 음악과 영상 제작 현황을 한눈에 보여주는 Studio 홈
- 자연어 프롬프트 기반 `Create Song & Video` 플로우
- 장르 믹스, 보이스, 캐릭터, 영상 스타일 설정
- 최근 프로젝트와 보이스·캐릭터 라이브러리 탐색
- 알림, 실행 메뉴, 제작 단계와 상태를 포함한 반응형 UI
